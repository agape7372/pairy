# 2. 포스타입(Postype) 벤치마킹 리포트

> 출처: `polymorphic-greeting-gizmo.md` §2 (§2.7 포함)

실사 페이지: 홈, `/request`(리퀘스트), `/premium/join`, 게시글 상세(`/@user/post/{id}`), 크리에이터 채널(`/@user`). 스크린샷 5종 확보.

## 2.1 정보구조(IA) · 탐색

- **좌측 고정 사이드바 + 상단 검색 + 중앙 피드** 3분할. 사이드바 1차: 홈 / 오픈 채널 / 리퀘스트 / 캐릭터톡 / 보관함. 리딩뷰 진입 시 사이드바가 **아이콘 레일로 축소** — 몰입 독서 모드.
- 홈 피드 상단 토글: **발견(`?feed-type=recommendation`)** vs **구독·참여(`?feed-type=subscription`)** — 탐색/팔로우 이원화.
- URL 체계 단순·의미론적: `/@user`, `/@user/post/{id}`, `/@user/request/{id}`, `/@user/series/{id}`. (페어리의 하드코딩 정적 라우트와 정반대 — 포스타입은 서버 렌더로 무한 UGC URL 서빙)

## 2.2 리퀘스트(커미션 마켓) — 페어리 자료/템플릿 마켓의 직접 대응물

- 정체성: "커미션 요청 플랫폼". **포인트(P) 경제** 기반(1,000P~40,000P 관찰).
- 카테고리 6종: 그림(만화·SD·고정틀) / 글(소설·편지·시) / **디자인(카톡테마·표지)** / 사주타로(운세·궁합) / 코칭(멘토링·과외) / 기타(플리·보정·번역). ← **디자인·고정틀 카테고리가 페어리 틀 상품과 정확히 겹침.**
- 정렬/필터 탭: 홈 / #재방문 BEST / #신상 BEST / 추천 / 신규 / 인기 / 후기. **후기(리뷰)를 1급 정렬축**으로.
- 성장장치: 뉴비 부스터, 할인 쿠폰(1,000P·10%, 만료 D-day·최소금액 조건), **X(트위터) 소문내기 선착순 1,500P**(레퍼럴). "지금 많이 찾는 태그" 트렌딩.

## 2.3 결제·구독 모델 — 2면 구조(중요)

- **소비자 프리미엄(QoL형)**: 라이트 2,500원/월, 플러스 4,300원/월(첫출시할인, 원가 2,900/5,400). 혜택 = 광고 제거 + 출석 포인트(플러스 최대 6,200P/월) + 태그 차단 + 비밀 댓글. → **콘텐츠 잠금 해제가 아니라 "쾌적함+포인트 환급".**
- **콘텐츠 결제(포인트)**: 유료 포스트(예: 100P) 개별 구매, 채널 구독, **후원(팁)**. (포스타입은 포인트 유효기간 90일로 체류 유도 — **페어리는 포인트 유효기간 도입 안 함, 사용자 결정 2026-07-05.** 창작자·구매자 신뢰 우선, 소멸 포인트로 인한 불만·CS 회피.)
- 법적 골격: **통신판매중개자** 고지 + 통신판매업 신고번호 명시("포스타입은 거래 당사자가 아님"). ← 한국서 실거래 시 필수. 페어리 마켓 오픈 전 반드시 갖춰야 할 컴플라이언스.

## 2.4 게시글·채널 UX

- 게시글: 제목 + **시리즈 페이지네이션(2/14)** + 작성자·날짜·조회수 + 태그 + **하단 플로팅 액션바**(이전 / ♡ / 댓글 / 리포스트 / 북마크 / 다음). 본문 아래 "이 채널의 인기 글" + "추천 포스트"(교차판매) + 댓글.
- 따뜻한 마이크로카피: "작가에게 힘이 되는 한마디 남기기…". 사회적 증거: "구독자 1,337명".
- 채널: 와이드 커버 + 원형 아바타 + 태그라인 + 외부링크 + 구독 버튼. 탭 = **활동 / 시리즈 / 커뮤니티**. 콘텐츠 타입 필터 칩(전체/포스트/리퀘스트/캐릭터톡/커뮤니티) + 채널 내 검색.

## 2.5 디자인 시스템(관찰)

- 화이트스페이스 많은 정갈한 레이아웃, 라운드 코너, **파스텔 악센트**(페리윙클/핑크/민트) + 파랑 프라이머리 CTA, 마스코트 일러스트(귀여운 토끼·고래). 카드 기반. — 페어리의 딸기크림 파스텔과 톤이 유사, **차별화가 색상만으로는 안 됨.**

## 2.6 벤치마킹 매트릭스 — 가져올 것 / 절대 안 할 것

| 항목 | 포스타입 강점(가져올 것) | 숨은 의도·심리 | 페어리가 따라하면 안 될 것 |
|---|---|---|---|
| IA | 사이드바→아이콘 레일 축소, 발견/구독 토글 | 몰입/회귀 동선 분리 | 5개 1차 메뉴 과다 — 페어리는 더 좁혀야 |
| 마켓 | 후기 1급 정렬, 트렌딩 태그, 카테고리 6종 | 신뢰(후기)·발견(태그) 선순환 | **포인트 유효기간(도입 금지·확정)**, 충전형 포인트 복잡성 — MVP엔 과함 |
| 결제 | QoL 구독 + 콘텐츠 포인트 **분리** | 저관여 진입(2,500원)→고관여 | 4단계 구독 난립(페어리 free/premium/duo/creator) |
| 게시글 | 플로팅 액션바, 시리즈 네비, 후원(팁) | 저마찰 수익화 | — (그대로 벤치마크 권장) |
| 컴플라이언스 | 통신판매중개자 고지 | 법적 방패 | 미고지 상태로 실거래 오픈(법적 리스크) |
| 카피 | "힘이 되는 한마디" 등 따뜻함 | 창작자 정서 케어 | 과한 마법 서사 남발로 기능성 흐리기 |

## 2.7 심층 재조사 추가 발견 (2026-07-05 2차 기능별 순회 — Playwright)

> claude-in-chrome 익스텐션 미연결·computer-use는 브라우저 읽기전용이라, 실제 클릭 순회는 Playwright(별도 세션, 비로그인)로 수행. 로그인 전용 플로우(발행·정산·구매완료)는 게이트까지 확인.

- **캐릭터톡 = 최애 AI 채팅(전략적 중요)**: character.ai류 AI 캐릭터 대화. **UGC 캐릭터 생성**("캐릭터 만들기") + **크리에이터 수익화**("파트너가 되어 캐릭터로 수익을") + **"포스트 원작" 배지**(발행 콘텐츠→AI 캐릭터 연결 루프) + **무료 대화권 일일 출석**(+5~15 점증, AI 채팅용 토큰경제) + 장르필터(로맨스/BL/GL/팬창작/성인19). → **동일 팬덤 타깃 경쟁 플랫폼이 이미 AI를 제품화·수익화**. 페어리의 "AI는 개발조직용"(§6) 판단에 대한 시장 반증 신호 — 향후 제품 내 AI(자캐 대화·설정 생성) 검토를 로드맵에 편입 고려.
- **오픈 채널 = 익명 게시판·캐입 롤플레이 커뮤니티**(팬창작/버튜버/동아리/캐입_게시판). 페어리 타깃(자캐 커뮤러)의 트위터 커뮤 행동을 포스타입이 흡수 중 — 위협이자, "틀 편집 후 → 커뮤에서 논다"는 후속 동선 벤치마크.
- **커미션 주문 UX(마켓 핵심)**: 기본가 + **옵션별 추가금**, **재고 쿼터("N개 남음")**, 작업기간(평균 1~7일), **후기에 구매옵션·기한준수율(100% 기한 준수)** 표기, **환불정책**(기한 초과 시 100% 자동환불), 작업물 사용권한·저작권 귀속 고지, 유사 리퀘스트 교차판매. → 페어리 틀 판매/커미션에 그대로 이식 가치 높음.
- **검색**: 타입 분리(`/search/channel`·`/search/post`) + 필터(`channelTypeFilter=OPEN` 등). 단순·의미론적.
- **가입/로그인(페어리 OAuth 벤치)**: 소셜 **구글·애플·네이버·이메일** — **트위터(X)·카카오 없음**. 미니멀. 페어리 타깃은 트위터 자캐러이므로 **Twitter/X OAuth는 페어리의 실차별 진입점**(포스타입 미제공). 단 iOS 심사 위해 애플 로그인 필요.
