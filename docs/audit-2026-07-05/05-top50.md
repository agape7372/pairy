# 9. 최우선 수정사항 TOP 50 (보안·인증 반영 최종 순위)

> 출처: `polymorphic-greeting-gizmo.md` §9

## Tier 0 — 보안 봉합 + 제품 성립 (지금 안 하면 나머지 무의미. 보안이 기능보다 앞선다)

1. **C-1 봉합**: `profiles` UPDATE에 `WITH CHECK`(또는 `role`/`total_earnings`/`pending_payout` 컬럼 권한 REVOKE + SECURITY DEFINER RPC). 권한 자가승격 차단 — 최우선.
2. **C-2 해소**: 라이브 DB `pg_dump` → 실제 스키마 커밋, `role` 컬럼 정본화. 소스=프로덕션 재현 가능 상태 복구.
3. **H-1 봉합**: `collab_sessions` `SELECT USING(true)` → host/participant 스코프 또는 invite_code 필터 RPC. 초대코드 덤프 차단.
4. 정적 export 결별: Vercel(Next 서버/ISR) 이전 또는 SPA catch-all 라우팅으로 UGC URL 서빙. (근본 원인)
5. `share/[shareId]`·`collab/[code]`·`creator/[username]`·`templates/[id]` 동적 서빙 복구(404 제거) + C-5 협업 join을 Supabase 경로로 배선.
6. 결제 백엔드(Toss 서버 라우트/웹훅) — 4와 묶어 해결.
7. **C-3/C-4 클라이언트 신뢰 제거**: 구독·구매·수익·정산을 서버(RLS 강제 테이블/Edge Function)서 검증. localStorage는 캐시로 강등.
8. H-5(env 누락 시 빌드 하드실패 + 데모모드 UI 배너), H-4(Supabase Auth 리밋/Turnstile), H-3(죽은 서버 인가 코드 제거).
