# 4. 적대적 검증 결과 (관점별)

> 출처: `polymorphic-greeting-gizmo.md` §4

- **투자자**: 매출 라인 0개 수금 가능(결제 전무) + UGC URL 404로 유기적 유입 불가 + 타깃 초협소(자캐 커뮤러)·CAC 모델 없음 + 손익분기 계산이 20구독자 흑자와 50K MAU 비용을 뒤섞은 내부 모순(13-operations.md). → **현 상태 투자 부적격. "데모는 예쁜데 사업이 없다."**
- **경쟁사**: 공격점 = (a) 공유링크가 404 → 바이럴 차단, 트위터에 페어리 링크 뿌려도 안 열림. (b) 협업이 동일기기 한정 → "우리는 진짜 실시간" 한 줄로 무력화. (c) 폰트 자산 0 → "우린 200폰트" 마케팅으로 우회.
- **해커(§5 확정 익스플로잇)**: (1) 콘솔 한 줄 `update({role:'super_admin'})`로 권한 승격(C-1). (2) `localStorage['pairy-subscription']` 편집 → 영구 무료 creator(C-3). (3) 가짜 Sale 주입 후 `requestPayout` → 없는 매출 출금(C-4). (4) `select('*') from collab_sessions`로 전 세션 초대코드·참가자 덤프(H-1). (5) 로그인 레이트리밋 시크릿창으로 우회 → 크리덴셜 스터핑(H-4). — **강점**: XSS/오픈리다이렉트/시크릿유출은 깨끗(L-2/3/4).
- **파워유저(창작자)**: 수익 정산 불가(결제 없음) + 틀 도난 방지(워터마크·우클릭·AI노이즈) 미구현 → 애초 페어리가 약속한 "도난 걱정 해결"이 공수표. 떠날 이유 = 핵심 약속 미이행.
- **일반유저**: 가입해도 콘텐츠가 데모뿐, 친구에게 공유하면 404, 모바일 편중이나 실기기 협업 안 됨. 가입 동기 부재.
- **개발자**: 기술부채 = god-component 2개, 무디바운스 히스토리, 통구독 리렌더, 폰트/섀도 이중 시스템, 죽은 데이터 경로, CI 게이트 부재.
- **운영자**: UGC 늘 때마다 라우트 재빌드·재배포 필요(정적) → 콘텐츠 1건마다 배포 = **운영 지옥**. 결제/정산 수기 대응 불가. 신고/관리자 도구 미구현으로 유해물 대응 불가.
