## 보안 회귀 (Tier 0 마이그레이션 적용 후 — 봉합 확인)
브라우저 콘솔(로그인 상태) 또는 SQL Editor에서:
| 검증 | 명령 | 봉합 전 | 봉합 후(기대) |
|---|---|---|---|
| C-1 권한 승격 | `await supabase.from('profiles').update({role:'super_admin'}).eq('id', (await supabase.auth.getUser()).data.user.id)` | 성공(치명) | **거부/무변경** |
| C-3 무료 프리미엄 | `localStorage.setItem('pairy-subscription', JSON.stringify({state:{subscription:{tier:'creator'}}}))` 후 새로고침 | 프리미엄 적용 | **서버 검증서 미반영**(서버 게이팅 구현 후) |
| H-1 세션 덤프 | `await supabase.from('collab_sessions').select('*')` | 전 세션 노출 | **본인 관련만** / 초대는 `get_collab_session_by_invite` |

> C-3는 클라이언트 신뢰 제거(서버 entitlement) 구현 후에 완전 봉합. 마이그레이션만으론 C-1/H-1 봉합.
