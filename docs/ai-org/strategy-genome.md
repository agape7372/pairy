# Strategy Genome — 페어리 전략 DNA

> 목적: 페어리의 정체성·경계를 **단일 정본**으로 고정한다. 스코프 스프롤 재발을 막는 앵커. 새 기능·요청은 이 문서와 대조 후 진행한다.
> 갱신 규칙: 전략이 바뀌면 여기서 바꾸고 [decisions/](./decisions/)에 DL 기록. 여러 문서에 흩어진 상충 값(가격 4종 등)을 만들지 않는다.

## 1. 정체성 (한 줄)
**자캐(OC) 창작자를 위한 틀 아카이브 + 페어틀 웹 에디터 + 실시간 협업.** (00-overview.md:9)

## 2. 타깃 (좁게, 명확히)
- 트위터/X 자캐 커뮤러, 10대 후반~30대 초, **~80% 여성**, 포토샵 접근성 낮음, 모바일 우선, "페어(캐릭터 페어링)" 문화.
- 페르소나: 민지(22, 학생, 포토샵 없음) · 수아(28, 틀 작가, 도난·수익화 고민).
- **문화적 사실**: 이 타깃은 **가명·익명**을 중시한다. 실명 소셜 로그인은 정서 역행 → [decisions/DL-0002.md](./decisions/DL-0002.md).

## 3. 핵심 가치 (Job to be done)
| 니즈 | 페어리의 답 |
|---|---|
| 틀이 트위터·포스타입에 흩어짐 | 통합 아카이브·검색 |
| 포토샵 없음 | 웹 에디터 |
| 혼자 못 만듦(2인 틀) | 실시간 협업 |
| 틀 도난 걱정 | 워터마크·도난방지 |
| 창작자 수익화 부재 | 마켓·후원 |

## 4. MVP 경계 — "2인 페어틀 하나에 올인" (00-overview.md:144)
**핵심**: 2인용 페어 틀 제작·공유·협업. 이것부터 완성한다.

## 5. 안 할 것 (Do-NOT list) — 스프롤 방지 확정 시드
> 이 목록은 "아무도 안 함을 결정하지 않아" 생긴 스프롤(PSD·게이미피케이션·4티어·Whisper·Duo 반쯤 병렬 구축)의 해독제다.
- ❌ **포인트 유효기간(소멸형)** 도입 — 사용자 결정 2026-07-05. 창작자·구매자 신뢰 우선.
- ❌ **4단계 구독 난립**(free/premium/duo/creator) — 2티어로 축소 지향.
- ❌ **Duo 구독**(2인 공동 구독) — 사용 UI 없는 과설계, MVP 밖. 코드 동결.
- ❌ MVP서 **3인+ 틀**, 복잡 포인트 충전·환불 경제, AI 노이즈 방지.
- ❌ 실명 기반 소셜 로그인(구글/카톡/네이버) — 최소 PII(이메일) 원칙.
- ⏸ **게이미피케이션(XP/뱃지)** — 코드는 양질이나 실 활동 생기기 전엔 배선 보류(defer, 컷 아님).
- ⏸ **Whisper**(창작자→구독자 선물) — 고유 아이디어나 현재 전송 no-op·과설계. 파운데이션 뒤로.

## 6. 해자 가설 (Moat hypotheses) — 검증 대상
1. **타깃 밀착**: 자캐 커뮤러 특화(Canva·포스타입이 안 하는 니치). ← 방어 가능성 중.
2. **실시간 2인 협업**: 현재 미작동(§감사). 진짜로 작동시키면 차별점. ← 재건 최우선.
3. **Twitter/X OAuth 진입점**: 포스타입도 미제공. 타깃이 트위터라 강력. ← 저비용 차별.
4. ⚠ 디자인·톤(파스텔)은 해자 아님 — 복제 쉬움. 포스타입도 파스텔.

## 7. 시장 신호 (경쟁 관찰)
- 포스타입 = 동일 팬덤 타깃. **캐릭터톡(AI 캐릭터 채팅)을 이미 제품화·수익화** + 오픈채널로 커뮤러 커뮤 흡수 중. → 페어리도 중기 **제품 내 AI**(자캐 설정/대화 생성) 검토 근거([../audit-2026-07-05/01-postype-benchmark.md](../audit-2026-07-05/01-postype-benchmark.md) §2.7).
- 실거래 오픈 시 **통신판매중개자** 고지 필수(포스타입 벤치).
