**WHAT**: 협업 세션 내 참가자 간 텍스트 채팅. 인프라(메시지 타입)는 존재하나 UI 컴포넌트는 미발견.

**현재상태**: partial(FACT, 인프라만). `broadcastProvider.ts`의 `BroadcastMessage` 타입(14-29행)에 `'chat-message'`가 선언돼 있으나(18행), `handleMessage()`의 switch문(160-193행)에는 `'chat-message'` case가 없어 default로 흘러 일반 리스너에만 전달됨 — 즉 채팅 메시지 타입은 정의됐지만 전용 핸들러 부재. `src/components/` 전역에서 채팅 관련 컴포넌트 grep 결과 0건 — **애플리케이션 레이어 UI가 아예 존재하지 않음**.

**스펙정합**: 문서에 협업 채팅이 명시적 스펙으로 존재하는지 불명(마스터 프롬프트 문서에 별도 언급 미확인) — 사실상 "존재한다고 추정됐으나 실제로는 미구현" 상태.

**문제·리스크**: 낮음(Low) — 애초에 사용자에게 노출된 기능이 아니므로(UI 없음) 현재 리스크는 "존재하지 않는 기능"이지 "고장난 기능"이 아님. 다만 감사 인벤토리에 F-14로 등재된 이상 향후 F-11 완성 시 자연스럽게 요구될 가능성.

**Fable판정**: **F-11 후 존치(사실상 신규 개발)** — 현재는 UI가 없으므로 "수정"이 아니라 "F-11 완성 후 신규 구현 여부 검토" 대상. 즉시 착수 대상 아님.
